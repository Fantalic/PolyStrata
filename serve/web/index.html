MCP servers

Their tools run on this PC with your rights, when the model decides to call them (in this page's chat only; switch it off in Sampling).

The API monitor is off

It keeps the last 100 requests' prompts and answers in memory, so it is off by default. To turn it on, add "api_monitor": true to the model's config file (strata-<model>.json) or start the server with --api-monitor, then restart it.

Model

One model is in memory at a time. Switching stops the current one first.

The model restarts with this window. A shorter window is faster; a longer one holds more history. Keeps the newest 16384 attention rows in VRAM and streams the rest from RAM in 4-bit. Frees VRAM at long contexts (384K context runs on an 8 GB card), but decodes about three times slower when the context is full (measured 12.1 vs 35.0 tok/s at a 258K prompt on a 3060 Ti; the all-resident q8_0 path is the faster choice at 262K). Off = the default path, byte-identical. From PR #180 by lepotane.
Conversation memory

How the engine keeps earlier chats ready, so returning to one does not read its whole prompt again. Each ? explains a setting. Apply now changes only this running engine; Save into config also keeps the values for every start.

Model settings
